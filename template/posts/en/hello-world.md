## Write in Markdown

Quarkdown renders your Markdown files as a single-page application. No build step required.

```javascript
const app = new Quarkdown({
  siteName: 'My Blog',
  languages: ['en'],
});
app.start();
```

## Features

- SPA routing with History API
- Markdown rendering with syntax highlighting
- Multi-language support (i18n)
- Pagination
- Open Graph meta tags for social sharing
- Starfield 404 page with warp effect
- Zero dependencies (CDN only)
